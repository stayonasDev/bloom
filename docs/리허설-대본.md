## Q&A 예상 질문 (기획서 v3 리스크 반론 순서)
1. 누가 삽니까 → 상담 AI 운영사와 평가 데이터 회사. 3곳이면 시작.
2. 영업비밀 아닙니까 → 회사 데이터를 받지 않는다. 로그 패턴은 서버가 거부한다(깨진 입력 데모 가능: `mock/broken/log-paste.json`). 완벽히 걸러낸다고는 말하지 않는다.
3. 블라인드면 뭘 믿고 삽니까 → 방금 본 Sealed Q&A.
4. 1000만 명이라기엔 작은데 → 첫 쐐기 5천 명. 입력이 인터뷰라 직군이 바뀌어도 코드가 안 바뀐다. 카드 목록의 5직군(통신·전자상거래·한국 통신·회계·병원 접수)을 가리킨다.
