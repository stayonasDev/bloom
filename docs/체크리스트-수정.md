## 1. 먼저 지켜 주셨으면 하는 것 (보안·봉인)
- [ ] **프론트에서 Supabase를 직접 호출하지 않기.** 카드·인계서·Q&A 전부 `/api/*`만 부릅니다. 카톡으로 받은 `.env.local`(NEXT_PUBLIC_SUPABASE_*)은 쓰지 않습니다. 이유: DB에 RLS가 없어서 공개 키로 `packs` 테이블을 읽으면 봉인된 인계서가 전부 열립니다.
- [ ] 클라이언트 컴포넌트에서 `@/lib/db`, `@/lib/env` import 없음 (`grep -rn "lib/db\|lib/env" src/app --include=*.tsx`)
- [ ] `NEXT_PUBLIC_` 환경변수에 어떤 키도 넣지 않음
- [ ] **구매 전에는 `/api/packs/{id}/note` 요청 자체를 보내지 않기.** 받아 놓고 CSS로 가리는 구현 금지. 403이 와도 인계서 영역은 빈 상태.
- [ ] `x-seller-id` / `x-buyer-id`는 `POST /api/sellers`, `POST /api/buyers` 응답으로 받아 localStorage에 보관. 새로고침해도 유지(안 그러면 구매 뒤 새로고침에 잠김)

## 2. 화면 1 — 인터뷰 (판매자)
- [ ] 제목 "Turn what you know into something that sells. No company data needed."
- [ ] role & years 입력 + 시드 4문항(Q1 What the manual never said / Q2 What new hires always get wrong / Q3 A request you refused, and why / Q4 A case the script couldn't solve)
- [ ] **"Load sample" 버튼** — `mock/sellers/telecom-billing-en.json`을 채움. 라이브에서 타이핑하면 "60초" 주장이 깨짐
- [ ] 제출 → `POST /api/interviews` → 꼬리질문 2개 표시(`target` 구분 없이 질문만) → 응답 입력 → "Seal my Handover Note" → `POST /api/interviews/{id}/seal` → 카드 화면 이동
- [ ] 하단 문구 "Don't paste logs or customer records. We only need your judgment."
- [ ] 422 거부 시 서버 `message`를 해당 문항(`error.field`) 아래 표시, 입력은 지우지 않음. `field` 없으면 폼 상단
- [ ] Claude 대기 중 버튼 비활성 + 진행 표시 (중복 클릭으로 인터뷰 2개 생기지 않음). 꼬리질문 약 4초, 추출 약 10초 걸림

## 3. 화면 2 — 블라인드 카드 + Sealed Q&A (구매자)
- [ ] 카드 목록 `GET /api/cards` → 카드 7필드 표시: Field / Language / Experience(`5 yrs`) / Difficulty(`4/5`) / Rarity(`4/5`) / Suggested(`$149 pack · $20/case`) / Listed(날짜·시각)
- [ ] 카드 상세 `GET /api/cards/{id}` → `unlocked`, `sealed_qa_count` 반영
- [ ] "Ask this pack" → `POST /api/cards/{id}/ask` → 답변 + "Based on {evidence_count} of {total_items} sealed items"
- [ ] `covered=false`면 답변 그대로 "This pack doesn't cover that." + "Based on 0 of N" 숨김
- [ ] 4번째 질문 429 → "Unlock the pack to keep asking." 표시, 입력창은 유지
- [ ] "Unlock full note $149" → `POST /api/packs/{id}/purchase {kind:"pack"}` → 성공 후 `GET /note` → 인계서 5섹션(Rules / Exceptions / Judgment calls / Common mistakes / Never do) + generalization 요약
- [ ] "Route cases to this expert" 는 목업 표시(눌러도 요청 안 나감, "Coming soon" 토스트)
- [ ] 인계서 어디에도 회사명이 보이지 않음(보이면 민수에게 알려 주세요, 샘플 문제인지 추출 문제인지 가름)
